Self-host

Your machine, the whole server.

From the v2 directory, build the image and start Compose. The app listens on port 18000. The console is on that same origin.

docker compose -f deploy/compose/compose.yaml build keys
docker compose -f deploy/compose/compose.yaml up -d

What starts

  • Postgres for the control schema and every project schema.
  • A second Postgres, for a project that moves to its own database.
  • An S3-compatible blob store.
  • Reactor, with PostgREST beside it inside the image.

Open http://127.0.0.1:18000/console and create the cluster. Project apps are served at http://{ref}.apps.localhost:18000/.

The same image is what you run on a VM, on Fly, or as Lambda. Clients keep the same URLs. The self-hosting guide covers configuration, the CLI, and the first project.
